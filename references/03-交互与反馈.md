# 交互与反馈

交互不是加分项，是基本盘。用户点下去没有反馈，他会再点一次，然后怀疑整个系统坏了。

三条原则：

- **即时**：响应在 100ms 内可见。做不到就给一个立即出现的过渡态（按下态、骨架）。
- **可预期**：同样的元素在同样的操作下给同样的反馈；动画方向符合空间直觉。
- **可逆**：误操作能撤销或能明确回到上一步。不可逆的动作必须提前确认。

---

## 1. 八种状态，缺一不可

| 状态 | 触发 | 表现要求 |
| --- | --- | --- |
| hover | 指针进入 | 背景/边框/阴影变化，可在 `@media (hover: hover)` 内做 1px 上移 |
| active | 指针按下 | 明显下沉或缩放，120ms 内完成 |
| focus-visible | 键盘聚焦 | 2px 外环 + 2px offset，必须与背景有 3:1 对比 |
| disabled | 不可用 | 降低对比但不低于可辨认，`cursor: not-allowed`，就近说明原因 |
| loading | 异步中 | 按钮内联 spinner + 文案切为进行时，禁止重复提交 |
| success | 成功 | 就地确认（行内状态变化优于 toast） |
| error | 失败 | 就地报错 + 重试入口，不要只弹 toast |
| empty | 无数据 | 说明这里会出现什么 + 一个可执行动作 |

---

## 2. 状态写法

```css
/* 只在支持 hover 的设备上做位移，触屏不会卡住悬停态 */
@media (hover: hover) and (pointer: fine) {
  .card {
    transition: transform var(--duration-base) var(--ease-out),
                box-shadow var(--duration-base) var(--ease-out);
  }
  .card:hover {
    transform: translateY(-1px);
    box-shadow: var(--shadow-md);
  }
}

/* 按下必须比悬停更明显，触屏同样生效 */
.btn:active {
  transform: scale(.97);
  transition-duration: var(--duration-fast);
}

/* 键盘焦点用 focus-visible，鼠标点击不出环 */
.btn:focus-visible,
.card:focus-visible {
  outline: 2px solid var(--color-primary);
  outline-offset: 2px;
}

.btn:disabled {
  opacity: .55;
  cursor: not-allowed;
  transform: none;
}
```

要点：

- 位移只做 1–2px，缩放只做 0.97–0.99。幅度大了像玩具。
- `transition` 只写在变化属性上，不要写 `transition: all`。
- 按下态在触屏也必须有（`:active`），悬停态只在支持 hover 的设备上做。

## 3. 拖拽

### 3.1 用 Pointer Events，不用 HTML5 drag

HTML5 `draggable` 在触屏上不可用、无法自定义 ghost、无法做细腻的落位提示。统一用 Pointer Events。

### 3.2 必备要素

1. **抓取面**：整行可拖，或提供明确的拖拽把手（grip 图标），把手 `cursor: grab`，拖动时 `grabbing`。
2. **ghost 跟随**：被拖元素跟随指针，带轻微旋转（1–2deg）与加深阴影，表示「拿起来了」。
3. **占位**：原位置留虚线框或半透明占位，保持布局高度不跳。
4. **让位动画**：其他元素移到新位置时用 200ms 过渡，不要瞬移。
5. **落位提示**：插入位置用一条 2px 主色指示线，不要只靠元素位移表达。
6. **边界**：拖到可视区外自动滚动；拖到非法区域显示禁止光标并不落位。
7. **取消**：`Esc` 取消拖拽并回弹原位。

```js
let drag = null;

list.addEventListener('pointerdown', (e) => {
  const handle = e.target.closest('[data-grip]');
  if (!handle) return;
  const row = handle.closest('[data-row]');
  row.setPointerCapture(e.pointerId);
  drag = { row, startY: e.clientY, offset: 0, moved: false };
  row.classList.add('is-dragging');
});

list.addEventListener('pointermove', (e) => {
  if (!drag) return;
  drag.offset = e.clientY - drag.startY;
  if (Math.abs(drag.offset) > 3) drag.moved = true;
  drag.row.style.transform = `translateY(${drag.offset}px) rotate(1deg)`;
  // 依据指针位置计算目标索引，给插入位加 .is-drop-target
});

list.addEventListener('pointerup', () => {
  if (!drag) return;
  drag.row.classList.remove('is-dragging');
  drag.row.style.transform = '';
  if (drag.moved) commitReorder();
  drag = null;
});
```

### 3.3 键盘等价

拖拽必须能用键盘完成，否则等于对键盘用户关闭该功能。做法：行可聚焦，`Alt + ↑ / ↓` 移动一位，移动后用 `aria-live` 播报「已移动到第 3 位」。

### 3.4 不要做

- 不要用拖拽承载唯一入口（必须有菜单里的「上移/下移」）。
- 不要让拖拽跨页面或跨窗口。
- 不要在长列表上做逐帧重排，改用虚拟滚动或只改 transform。

## 4. 滑动

用于触屏的列表行操作（左滑露出删除、右滑标记已读）。

```css
.swipe-row {
  touch-action: pan-y;      /* 只接管横向，纵向滚动交给浏览器 */
  overflow: hidden;
}
.swipe-row__inner {
  transition: transform var(--duration-base) var(--ease-out);
  will-change: transform;
}
```

规则：

- 阈值：滑动距离超过行宽 40% 或 96px 才吸附展开，否则回弹到 0。
- 展开态显示动作按钮，单行最多 2 个动作，危险动作放最外侧。
- 同一列表只允许一行处于展开态，打开新的自动收起旧的。
- 必须有回弹动画，不能瞬移。
- 桌面端不启用滑动（没有触摸），提供等价的 hover 操作或行内菜单。

## 5. 长按

用于触屏上唤出上下文菜单或进入多选模式。

```js
const LONG_PRESS = 500;

function bindLongPress(el, onFire) {
  let timer = null, startX = 0, startY = 0, cancelled = false;

  const cancel = () => { clearTimeout(timer); timer = null; el.classList.remove('is-pressing'); };

  el.addEventListener('pointerdown', (e) => {
    if (e.pointerType === 'mouse') return;      // 鼠标用右键菜单
    startX = e.clientX; startY = e.clientY; cancelled = false;
    el.classList.add('is-pressing');            // 触发 SVG 圆环进度动画
    timer = setTimeout(() => { if (!cancelled) onFire(); cancel(); }, LONG_PRESS);
  });

  el.addEventListener('pointermove', (e) => {
    if (Math.hypot(e.clientX - startX, e.clientY - startY) > 8) { cancelled = true; cancel(); }
  });

  ['pointerup', 'pointercancel', 'pointerleave'].forEach((t) =>
    el.addEventListener(t, () => { cancelled = true; cancel(); })
  );
}
```

必须有的配套：

- **进度反馈**：500ms 是很长的时间，必须给可见反馈（圆环描边进度、背景渐深、轻微缩放）。
- **取消条件**：移动超过 8px、抬起、多点触控、滚动开始。
- **触发后抑制 click**：长按触发菜单后，抬起时不要再触发一次普通点击。
- **桌面等价**：鼠标用右键菜单，不要让桌面用户去长按。

## 6. 双击、右键与键盘

- 双击：只用于「进入编辑」这类低风险动作，且必须同时提供单击可见的入口。双击不与单击混用在同一元素上。
- 右键菜单：自定义菜单时保留浏览器默认行为不可用的场景判断（输入框内不拦截）；菜单支持 Esc 关闭、方向键移动、点击外部关闭。
- 键盘：Tab 顺序符合视觉顺序；Enter/Space 触发按钮；Esc 关闭浮层；方向键在列表与菜单内移动；`Cmd/Ctrl+Z` 支持撤销可撤销的操作。

## 7. 动效

| 场景 | 时长 | 缓动 |
| --- | --- | --- |
| 颜色、透明度、边框 | 120ms | `--ease-out` |
| 悬停、按下、展开折叠、图标旋转 | 200ms | `--ease-out` |
| 抽屉、弹窗、面板进出 | 320ms | 进 `--ease-out`，出 `--ease-in-out` |
| 骨架微光 | 1200ms 循环 | `linear` |

规则：

- 只对 `transform` / `opacity` / `color` / `box-shadow` / `border-color` 做过渡，不对 `width` / `height` / `top` / `left` 做过渡（会引起重排）。
- 进入动画比退出动画稍慢，退出要干脆。
- 同屏最多一个持续动画（骨架或 spinner），不要多个呼吸灯一起闪。
- 动效服务于状态变化，不做装饰性循环动画。

```css
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: 1ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: 1ms !important;
    scroll-behavior: auto !important;
  }
}
```

降级后所有状态变化仍然可见（瞬间切换），功能不丢。

## 8. 加载与提交

- 小于 200ms 的请求不显示 loading（闪一下更烦）；200ms 以上显示。
- 超过 1s 的等待给骨架或进度；超过 10s 给可中断的进度与说明。
- 提交按钮：点击后立即禁用并切文案为「提交中」，防重复提交；失败后恢复并保留用户输入。
- 乐观更新：可逆的轻量操作先更新 UI 再同步，失败时回滚并提示；不可逆操作不做乐观更新。
- 列表加载更多用追加骨架，不要清空当前列表。

---

## 9. 危险操作

- 优先「可撤销」：删除后 5 秒内可在 toast 上撤销，比弹窗确认体验更好。
- 不可撤销才用弹窗确认，且弹窗必须写清后果（见 `references/02-文案与信息层级.md`）。
- 破坏性操作不要做「是/否」对称按钮，主按钮用危险色并写明动作：`作废并终止流程`。
- 批量危险操作要求输入数量或对象名二次确认（例如输入「12」确认删除 12 条）。

---

## 10. 触屏与响应式

- 可点元素热区最小 44×44px，视觉尺寸可以小，用 padding 撑开。
- 不依赖 hover 表达信息（触屏没有 hover），hover 只是增强。
- 手势阈值按设备区分：触屏用 8px 起判、96px 吸附；鼠标用 3px 起判。
- 底部固定操作条要处理 `env(safe-area-inset-bottom)`。
- 抽屉在窄屏（< 768px）改为全屏页面，不要横向溢出。

组件宽度、字号与缩放的完整规则见 `references/07-弹性尺寸与缩放适配.md`，本节的 44px 是热区下限，不是组件固定尺寸。

---

## 11. 可访问性底线

- 所有交互元素可 Tab 到、可 Enter/Space 触发。
- 弹窗/抽屉：打开时焦点移入第一个可聚焦元素，焦点陷阱生效，Esc 关闭，关闭后焦点归还触发元素。
- 状态变化用 `aria-live="polite"` 播报（提交成功、校验失败、排序变化）。
- 图标按钮必须有 `aria-label`；纯装饰图标 `aria-hidden="true"`。
- 颜色不作为唯一信息载体：错误态除红色外还要有图标与文字。

---

## 12. 自检

- [ ] 每个可交互元素都有 hover、press、focus-visible 三态
- [ ] 按下态在触屏上可见（`:active` 生效）
- [ ] 禁用态能看出被禁用，且用户知道原因
- [ ] 提交有防重与进行时文案
- [ ] 拖拽有 ghost、占位、落位指示、Esc 取消、键盘等价
- [ ] 滑动有阈值、回弹、互斥展开、桌面等价入口
- [ ] 长按有进度反馈与取消条件，不误触发点击
- [ ] 动效只碰 transform/opacity/color/shadow
- [ ] `prefers-reduced-motion` 有降级且功能不丢
- [ ] 弹窗与抽屉的焦点陷阱、焦点归还、Esc 关闭都实现
- [ ] 热区 ≥ 44px，不依赖 hover 传递关键信息
- [ ] 没有 `transition: all`、没有滚动劫持、没有无意义循环动画
