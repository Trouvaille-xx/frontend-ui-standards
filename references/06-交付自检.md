# 交付自检

这份文件是闸门，不是参考。任何一条不过，就不要交付，回去改。

三种用法：

- **开发中**：每做完一个区块，过一遍对应闸门，别攒到最后。
- **交付前**：六道闸门全过，再跑自动化脚本。
- **评审时**：用闸门条款指出问题编号，不用「感觉有点乱」这种说法。

---

## 闸门 A：主色与视觉

- [ ] 主色不在黑 / 紫 / 深蓝 / 伪中性深蓝区间
- [ ] 没有把 `#000` `#111` 一类近黑当主题色
- [ ] 没有整站深色底 + 荧光主色的科技风
- [ ] 主色与白底对比度：正文 ≥ 4.5:1，大字与图标 ≥ 3:1
- [ ] 主色压白字时，白字对比度 ≥ 4.5:1（600 档常常不达标，要升到 700）
- [ ] 主色浅底（soft）上的主色文字，用的是 800 档而不是 700 档
- [ ] 全站主色只有一个，没有两个主色抢主导
- [ ] 中性色来自同一套 token，没有随手写 `#f5f5f5`
- [ ] 深色模式下主色提亮一档，且深色模式同样不出现紫与深蓝

## 闸门 B：文案

- [ ] 没有一句「系统怎么实现的」「数据从哪来」
- [ ] 没有复述控件自身状态（只读、必填、格式、不可修改）
- [ ] 没有解释设计理由的句子
- [ ] 没有灰底备注框、没有「功能说明」段落
- [ ] 没有禁用词：`注：` `说明：` `温馨提示` `点击此处` `系统自动生成` `不可修改` `后台`
- [ ] 每条保留的提醒都写清了「后果 + 建议动作」
- [ ] 同一条信息没有在多处重复
- [ ] 字段帮助与提醒样式不同、位置不同
- [ ] 空状态 / 错误 / 无权限都给了可执行的下一步
- [ ] 按钮文案是动词 + 对象，没有 `确定` 这种空动作（唯一上下文除外）

## 闸门 C：结构

- [ ] 能用一句动词短语说出这个页面的唯一主任务
- [ ] 页面上只有一个视觉主导的主按钮
- [ ] 一屏内同级区块 ≤ 3
- [ ] 列表、详情、编辑、日志、说明不在同一层
- [ ] Tab / 弹窗 / 抽屉 / 菜单 / 多级页面选型正确（对照 `references/04-信息架构与页面分层.md` 第 5 节）
- [ ] 弹窗里没有表格、没有多步流程、没有嵌套弹窗
- [ ] 返回上一级后筛选、排序、滚动位置保留
- [ ] 导航不超过 3 级，当前位置可见

## 闸门 D：交互

- [ ] 每个可交互元素有 hover / press / focus-visible 三态
- [ ] 触屏上按下态可见
- [ ] 提交有防重复与进行时文案
- [ ] 拖拽有 ghost、占位、落位指示、Esc 取消、键盘等价
- [ ] 滑动有阈值、回弹、互斥展开、桌面等价入口
- [ ] 长按有 500ms 进度反馈，移动 8px 或抬起即取消
- [ ] 动效只碰 `transform` / `opacity` / `color` / `box-shadow`，没有 `transition: all`
- [ ] `prefers-reduced-motion` 有降级，功能不丢
- [ ] 弹窗与抽屉有焦点陷阱、焦点归还、Esc 关闭
- [ ] 热区 ≥ 44×44px
- [ ] 没有滚动劫持、没有无意义循环动画

## 闸门 E：图标与资源

- [ ] 全站零 emoji（含 `U+2600–27BF` 与变体选择符）
- [ ] 图标是内联 SVG，`viewBox="0 0 24 24"`、`1.5` 描边、圆角端点
- [ ] 图标颜色用 `currentColor`，跟随父级
- [ ] 尺寸只用 16 / 20 / 24，宽高同步
- [ ] 装饰图标 `aria-hidden="true"`，图标按钮有 `aria-label`
- [ ] 没有 icon font、没有位图图标、没有线性与填充混用
- [ ] 图标没有被拉伸变形

---

## 闸门 F：弹性尺寸与缩放

- [ ] 无写死的容器宽度（`width: 1120px` 这类），页面容器是 `min(上限, 100% - 边距)`
- [ ] 组件无固定 `width` / `height`，改用 `min-height` + `padding`
- [ ] 字号全部 `rem` 或 `clamp()`，无 `font-size: Npx`
- [ ] 无 `100vh` / `100vw` / `zoom` / 布局用 `transform: scale()`
- [ ] flex 子项有 `min-width: 0`，grid 列用 `minmax(0, 1fr)`
- [ ] 文本容器无固定高度，长文本有 `overflow-wrap: anywhere`
- [ ] 图片有 `max-width: 100%; height: auto`
- [ ] 宽表格与代码块有 `overflow-x: auto` 容器，页面本身不横向滚动
- [ ] 组件用 `@container` 自适应容器宽度，而非只依赖全局断点
- [ ] Windows 缩放 125% / 150% / 200% 实测无横向滚动、无裁字
- [ ] 窗口 365px 宽实测正常换行，弹窗不超出屏幕

## 自动化脚本

结构性判断查不出来，但机械项必须先机器过一遍，不要靠眼睛。

### PowerShell

```powershell
$file = '.\index.html'
$h = [IO.File]::ReadAllText((Resolve-Path $file), [Text.Encoding]::UTF8)

$checks = [ordered]@{
  'emoji'        = '[\uD800-\uDBFF][\uDC00-\uDFFF]|[\u2600-\u27BF\u2B00-\u2BFF\uFE0F]'
  'emoji 实体'    = '&#x1F[0-9A-Fa-f]{3};|&#12[7-9][0-9]{3};|&#1[3-9][0-9]{4};'
  '说明性文案'    = '注：|说明：|温馨提示|点击此处|系统自动生成|不可修改|本功能|该字段'
  '禁用主色'      = '(?i)#(?:000000|111111|1a1a1a|1f1f1f|7c3aed|8b5cf6|6366f1|a855f7|1e3a8a|1e40af|1d4ed8|2563eb|0f172a|111827|1e293b)'
  'transition:all' = 'transition\s*:\s*all'
  '固定尺寸'      = '(?<![a-z-])(?:width|height)\s*:\s*[0-9]{2,}px|font-size\s*:\s*[0-9]+px|100vh|100vw|(?<![a-z-])zoom\s*:'
  'icon font'    = 'font-family\s*:\s*["'']?[^;]*(?:icon|awesome|material)'
  '滚轮劫持'      = 'preventDefault\(\)[\s\S]{0,80}wheel'
}

$fail = 0
foreach ($k in $checks.Keys) {
  $n = [regex]::Matches($h, $checks[$k]).Count
  if ($n -gt 0) { $fail++; Write-Host ("[FAIL] {0} 命中 {1} 处" -f $k, $n) }
  else { Write-Host ("[PASS] {0}" -f $k) }
}
if ($fail -gt 0) { Write-Host "闸门未通过，共 $fail 项"; exit 1 } else { Write-Host '自动化项全过，继续人工过六道闸门' }
```

### bash / grep

```bash
f=index.html
! grep -qP '[\x{1F300}-\x{1FAFF}\x{2600}-\x{27BF}]' "$f" && echo "emoji PASS"
! grep -qE '注：|说明：|温馨提示|点击此处|系统自动生成|不可修改' "$f" && echo "文案 PASS"
! grep -qiE '#(000000|111111|1a1a1a|7c3aed|8b5cf6|6366f1|1e3a8a|1e40af|1d4ed8|0f172a|111827)' "$f" && echo "主色 PASS"
! grep -qE 'transition\s*:\s*all' "$f" && echo "动效 PASS"
! grep -qE '(^|[^-])(width|height)\s*:\s*[0-9]{2,}px|font-size\s*:\s*[0-9]+px|100vh|100vw' "$f" && echo "弹性 PASS"
```

| 页面底部灰底框「功能说明：……」 | B | 移入帮助中心 |

| Tab 里再套 Tab | C | 改详情页 + 分组 |

| 提交后可重复点击 | D | 点击即禁用 + 进行时文案 |

| 标题前挂装饰性 emoji（火箭、闪光、图钉那一类） | E | 删，或用 SVG 图标 |

| 图标 20×24 拉伸 | E | 宽高同步 |

## 交付时附的四行声明

交付产物必须附这四行，写不出来说明层级与尺寸策略都没定：

```
唯一主任务：<一句动词短语>
信息分层：<一级放什么；详情/编辑/说明分别在哪一层>
主色与视觉主角：<主色 hex + 来自哪套 token；视觉主角是什么>
尺寸策略：<容器宽度上限 / 用到的断点或容器查询 / 缩放实测结论>
```

评审先看这四行，再看页面。四行对不上页面，直接打回。

---

## 判定口径

| 结论 | 条件 |
| --- | --- |
| 通过 | 六道闸门全过，自动化脚本全 PASS，四行声明与页面一致 |
| 需整改 | 至多 2 项不过，且不属于主色、结构、写死尺寸类 |
| 打回 | 主色违规、一页面板式、页面出现功能说明、出现 emoji、写死尺寸导致 125% 缩放横向滚动，任一命中 |

主色违规、一页面板式、功能说明、emoji 这四项是硬伤，不允许「先上，下版改」。它们会固化成模板，后续所有页面都会跟着错。
