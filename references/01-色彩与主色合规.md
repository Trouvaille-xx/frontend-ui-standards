# 01 色彩与主色合规

## 1. 主色的定义与边界

主色是品牌色、主题色和大面积视觉主导色，落点是主按钮、选中态、链接、图表主序列、顶栏和 Hero 区底色，用户换一个产品最先记住的就是它。

命中任意一项，这个颜色就按主色管理：

- 主按钮的填充、悬停态、按下态
- 选中态：Tab 下划线、选中行、选中卡片边框、开关与复选框的开启色
- 链接文字与链接图标
- 图表第一序列、进度条、数据高亮的基准色
- 顶栏、侧边栏选中项、Hero 区大面积底色
- 换肤时被写进 `--color-primary` 的那个色

不算主色的部分：正文文字、标题文字、次要文字、边框、分割线、禁用态、纯装饰图形。这些走第 5 节的中性色阶，不参与主色合规判定。正文文字不用 #000，统一用中性深灰 #2B2F36（白底 13.44:1）；#000 只允许出现在 ≥32px 的单处超大字标题，默认不用。

一个产品只设一个主色。同一屏出现第二个与本主色不同色相的高饱和色，按违规处理；图表序列和成功、警告、失败这类语义色除外，规则见第 4 节。

## 2. 违规判定表

| 颜色族 | 色相 H 范围 | 明度与彩度条件 | 典型违规 hex | 后果 |
| --- | --- | --- | --- | --- |
| 中性近黑当主色 | H 任意（无彩） | L ≤ 12% 且 S < 10% | #000000 #111111 #1A1A1A #1F1F1F | 主色与正文、边框、图标挤在同一明度带，选中态只能靠加粗和描边区分，页面像未套样式的系统控件 |
| 紫色族（含靛青） | H 236–305，靛青落在 236–250 | 任意 L，要求 S ≥ 30% | #7C3AED #8B5CF6 #A855F7 #6366F1 #9333EA #C084FC | 与 2021 年后 AI 模板的默认配色重合，两个不同产品放一起无法区分 |
| 深蓝族 | H 205–250 | L < 45% 且 S ≥ 30% | #1E3A8A #1E40AF #0F2C5C #0F172A #172554 | 大面积铺开把界面压成一块深色板，层级只能靠 1px 分割线硬撑 |
| 宝蓝（深蓝扩展） | H 205–250 | 45% ≤ L < 62% 且 S ≥ 30% | #1D4ED8 #2563EB #3B82F6 | 默认模板蓝，白字对比不足只能加深，加深就落进深蓝档，等于换个方式违规 |
| 伪中性深蓝 slate | H 210–230 | L ≤ 20%，S 在 33–48% 之间 | #0F172A #111827 #1E293B | 看着像中性灰，实际带蓝彩，当主色、侧边栏底或表头底时与真深蓝同罪，还会让整套中性色阶偏蓝 |

深蓝族的 L < 45% 与宝蓝档的 L < 62% 合起来覆盖 H 205–250 里 L < 62% 的全部明度，这个色相区间没有可用作主色的位置。L ≥ 62% 的浅蓝不在禁用表内，但它与白底的对比度不足 3:1，承载不了白字，也做不了主色，只剩装饰用途，视同不可用。

### 2.1 判定口径

判定统一用 HSL，不用 RGB 或 hex 直觉。H 取 0–360 表示色相，S 取 0–100% 表示彩度，L 取 0–100% 表示明度，三者取整后套表。任何设计稿色值、CSS 变量、图表配置里的颜色，先转 HSL 再判，转换脚本见第 9 节。

判定步骤：

1. 先看 H 定族：落在 236–305 的问一句是不是紫（靛青 #6366F1 在 239，算紫）；落在 205–250 的问一句是不是蓝。
2. 再看 S 定彩：S ≥ 30% 才算有彩，紫族和蓝族都要求 S ≥ 30%；S < 10% 的色直接进近黑档判断。
3. 最后看 L 定深浅：S < 10% 且 L ≤ 12% 判近黑；蓝族再按 L < 62% 收口，L < 45% 记深蓝，45% ≤ L < 62% 记宝蓝。
4. 命中任意一条就判违规，不再讨论"深一点浅一点能不能用"。
5. 以上都不命中，才进入第 6 节的对比度筛选。

判定口诀：H 分族、S 分彩、L 分深浅。H 236–305 且 S ≥ 30 判紫；H 205–250 且 S ≥ 30 且 L < 62 判蓝；S < 10 且 L ≤ 12 判近黑；三条都不命中，才允许往主色上试。

判定区间已经留了余量：紫族样本的实际 H 是 239–271，蓝族样本是 217–226，落在区间边缘 2 度以内的色按更严的一档处理。

## 3. 为什么禁

1. 审美上直接撞模板。黑、紫、深蓝是 UI 模板库和生成式工具的首选默认值，用户见过太多次，第一眼就把页面归为套壳，品牌识别度归零。
2. 层级被压平。近黑或深蓝当主色时，主色、正文、边框、图标处在同一明度带，选中态与普通态只能靠加粗、下划线、1px 分割线区分；投影、暗屏、压缩截图下几乎不可辨，色块对比退化成线条堆叠。
3. 与禁令 4 一页面板式互为因果。一页面板式需要深色主色压住版面，主色面积一大层级更糊，于是再加面板和分割线；反过来主色偏弱时又靠多开面板来分区。两条一起改才有效：主色只承担一个强调角色，版面靠留白和层级拆分（全局导航、页面、Tab、区块、抽屉），不靠堆面板。

| 青绿 teal（默认） | #0F766E | H175 S77 L26 | 5.47:1 | 默认主色；B 端后台、表格、看板 | #115E59 | #134E4A | #E7F1F0 |
| 翠绿 green | #15803D | H142 S72 L29 | 5.02:1 | 增长、健康、环保、收益类产品 | #166534 | #14532D | #E8F2EC |
| 琥珀 amber | #B45309 | H26 S90 L37 | 5.02:1 | 审核、待处理、内容型产品 | #92400E | #78350F | #F8EEE6 |
| 珊瑚 coral | #C1442F | H9 S61 L47 | 5.08:1 | 活动、消费、需要强引导的 C 端 | #A63A29 | #8B3022 | #F9ECEA |
| 天青 cyan | #0E7490 | H193 S82 L31 | 5.36:1 | 工具、技术、开发者产品 | #155E75 | #164E63 | #E7F1F4 |
| 玫瑰 rose | #BE123C | H345 S83 L41 | 6.29:1 | 会员、生活方式、女性向产品 | #9F1239 | #881337 | #F8E7EC |

选用规则：

- 六个候选互斥，一个产品只选一个；其余五个只作为换主题时的备选，不进入同一套配色，也不得同时承担主色。
- 白字压在主色上必须具备 4.5:1，上表六个候选全部满足（5.02–6.29），这是它们当选的硬门槛。#0D9488（3.74:1）、#16A34A（3.30:1）、#D97706（3.19:1）这一档只能做图标或 ≥24px 大标题，不做 14px 白字按钮。
- 图表序列：第一序列用主色，第二序列用同色系 600 档（teal 取 #0D9488），第三序列用 #6A7180。不要为第二序列引入另一种彩色，那等于第二个主色。
- 悬停与按下只允许沿同一色相加深（600 加深到 700、800、900），不允许换色相。
- 浅色底（10% 混合）用于选中行、标签底、提示条，不得承载白字。

## 5. 中性色阶

| 档位 | Hex | HSL | 用途 | 与白底对比度 |
| --- | --- | --- | --- | --- |
| 1 | #FFFFFF | H0 S0 L100 | 页面底 | 1.00:1 |
| 2 | #F7F8FA | H220 S23 L97 | 卡片面、区块分组底 | 1.06:1 |
| 3 | #EFF1F4 | H216 S19 L95 | 悬停底、斑马纹、输入框底 | 1.13:1 |
| 4 | #E3E6EB | H217 S17 L91 | 常规边框、分割线 | 1.25:1 |
| 5 | #CBD0D8 | H217 S14 L82 | 输入框边框、强分割 | 1.55:1 |
| 6 | #9BA1AB | H218 S9 L64 | 禁用文字、装饰图标 | 2.60:1 |
| 7 | #6A7180 | H221 S9 L46 | 次要文字、占位文字 | 4.90:1 |
| 8 | #2B2F36 | H218 S11 L19 | 正文 | 13.44:1 |
| 9 | #12141A | H225 S18 L9 | 标题 | 18.41:1 |

使用规则：

- 正文用 #2B2F36，标题用 #12141A 或直接沿用正文色。纯黑 #000 不用：21:1 的极端对比在暗光下发刺，深色区域边缘还会出现光晕。
- #12141A 只用于文字，不写进 `--color-primary`，也不做按钮或标签的底色。
- 次要文字 #6A7180 只在 #FFFFFF 和 #F7F8FA 上合格（4.90 / 4.61）；放在 #EFF1F4 上只有 4.33，先把底改成 #FFFFFF 或把文字升到 #2B2F36。
- 禁用文字 #9BA1AB 只在禁用态使用（2.60），禁用态本身不承担操作信息；占位文字不用它，占位文字用 #6A7180。
- 边框只负责划分区域，不承担选中、可用、错误这类信息。凡是用边框表达状态的地方，改成主色描边加图标或文字。
- 中性灰的 S 不超过 18%，深色底再收紧到 10% 以内；S 一旦进到 30% 并落在 H 205–250，就按第 2 节的深蓝族处理。

## 6. 文字与背景对比度规则

| 内容类型 | 最小对比度 | 合格示例 | 不合格示例 |
| --- | --- | --- | --- |
| 正文（16px 常规） | 4.5:1 | #2B2F36 on #FFFFFF = 13.44:1 | #6A7180 on #EFF1F4 = 4.33:1 |
| 次要文字（12–14px） | 4.5:1 | #6A7180 on #FFFFFF = 4.90:1 | #9BA1AB on #FFFFFF = 2.60:1 |
| 大字号（≥18.66px bold 或 ≥24px 常规） | 3:1 | #0F766E on #FFFFFF = 5.47:1 | #D97706 on #FFFFFF = 3.19:1 只在大字号可用 |
| 图标与控件轮廓（承载信息时） | 3:1 | #2B2F36 图标 on #FFFFFF = 13.44:1 | #CBD0D8 图标 on #FFFFFF = 1.55:1 |
| 禁用态文字 | 2.5:1 起，且必须仍能辨认 | #9BA1AB on #FFFFFF = 2.60:1 | 禁用态用 #E3E6EB 文字（1.25:1，看不出是文字） |
| 分割线与装饰 | 不设门槛，建议 1.2:1 以上 | #E3E6EB on #FFFFFF = 1.25:1 | 用分割线代替层级划分 |

主色与文字的两类组合，取舍规则：

- 规则 A，主色填充配白字：只用于主按钮、选中项、徽标、顶栏这类需要一眼看到的元素。主色与白色必须 ≥4.5:1，达不到就沿色相加深一档（600 换 700）。第 4 节六个候选全部满足。
- 规则 B，白底配主色字：用于链接、强调文字、图标，用主色 700 档（5.02–6.29）。600 档与白底只有 3.19–4.70，除大字号和大图标外不合格。
- 规则 C，浅色底配主色字：底用主色的 10% 混合，文字必须升到 800 档。700 档压在浅色底上只剩 4.33–4.75：green 4.38、amber 4.39、rose 4.33、coral 4.40 直接不合格，teal 4.75、cyan 4.67 刚好过线不留余量。合格配对：teal #115E59 配 #E7F1F0 = 6.59；green #166534 配 #E8F2EC = 6.23；amber #92400E 配 #F8EEE6 = 6.20；coral #A63A29 配 #F9ECEA = 5.59；cyan #155E75 配 #E7F1F4 = 6.33；rose #9F1239 配 #F8E7EC = 6.73。
- 规则 D，大面积主色底配白字：Hero、侧边栏、顶栏这类面积超过一屏 20% 的区域，用主色 700 或 800 档；浅色底不承载白字。
- 规则 E，一个元素只用一种强调：主色填充配白字、浅色底配主色字，二选一，不要在主色按钮里再嵌一层浅色底文字。

自算方法：相对亮度 L = 0.2126R + 0.7152G + 0.0722B，通道值先除以 255，再按 c ≤ 0.03928 取 c/12.92、否则取 ((c + 0.055)/1.055)^2.4；对比度 = (L1 + 0.05) / (L2 + 0.05)，L1 取亮者。本文所有对比度均按此公式计算，保留两位小数。

## 7. 深色模式规则

- 默认交付浅色。深色只在 `prefers-color-scheme: dark` 或用户显式开启时启用，不为深色单独设计一套新配色，只换中性层和主色明度。
- 底色用中性炭灰：页面底 #24262A（S8），卡片面 #2C2F34，边框 #3A3E45，正文 #E8EAED（12.57:1），次要文字 #A8AEB8（6.79:1），占位与禁用 #6A7180（3.09:1）。不用 #000，纯黑在 OLED 上会让边界糊、渐变色带断裂。
- 炭灰色的 S 控制在 10% 以内。#0F172A 的 S 是 48%、#111827 是 40%、#1E293B 是 33%，它们是深蓝族而不是炭灰，深色模式同样禁用。
- 主色在深色下提亮一档，映射如下：

| 浅色主色 | 深色主色 | 深色底 #24262A 上的对比度 |
| --- | --- | --- |
| #0F766E | #2DD4BF | 8.14:1 |
| #15803D | #4ADE80 | 8.70:1 |
| #B45309 | #FBBF24 | 9.08:1 |
| #C1442F | #FF8A70 | 6.58:1 |
| #0E7490 | #22D3EE | 8.39:1 |
| #BE123C | #FB7185 | 5.63:1 |

- 深色下主色填充配深色文字：文字用 #12141A 或 #24262A，对比度 8.14–9.08；不要用白字，白字压在 #2DD4BF 上只有 1.86:1。
- 深色下大面积主色区改用深色浅底 #143835（teal 家族的深色浅底，S47 H175），主色只用于文字、描边和按钮。主色铺满一屏，深色模式会回到界面被压成一块的老问题。
- 深色模式逐条适用第 2 节判定表：深蓝底、紫底、近黑底一律不接受。深色下的"近黑"指 L ≤ 12% 且 S < 10% 的底色，它与炭灰 #24262A（L15 S8）只差 3 个明度点，取 L15 及以上的炭灰才稳。

| 侧边栏底色 | `background: #111827` | S40 H221，是深蓝族不是中性色；与正文对比不足，选中项只能靠分割线 | 底 #24262A，选中项左侧 3px 主色条 #0F766E 加 #E8EAED 文字，未选中文字 #A8AEB8 |

## 9. 检查方法

把下面脚本存成 `check-main-color.ps1`，对产物代码目录跑一遍，命中即列出文件、行号、色值与命中原因，有命中时退出码为 1，可以接进提交前钩子。

```powershell
param(
    [Parameter(Mandatory = $true)][string]$Path,
    [string[]]$Extensions = @('.css', '.scss', '.less', '.html', '.vue', '.jsx', '.tsx', '.js', '.ts', '.svg', '.json')
)

$hexPattern = '#[0-9A-Fa-f]{8}\b|#[0-9A-Fa-f]{6}\b'

function ConvertTo-Hsl([string]$hex) {
    $d = '0123456789ABCDEF'
    $s = $hex.Substring(1, 6).ToUpper()
    $r = [double]($d.IndexOf($s[0]) * 16 + $d.IndexOf($s[1])) / 255
    $g = [double]($d.IndexOf($s[2]) * 16 + $d.IndexOf($s[3])) / 255
    $b = [double]($d.IndexOf($s[4]) * 16 + $d.IndexOf($s[5])) / 255
    $max = $r; if ($g -gt $max) { $max = $g }; if ($b -gt $max) { $max = $b }
    $min = $r; if ($g -lt $min) { $min = $g }; if ($b -lt $min) { $min = $b }
    $l = ($max + $min) / 2
    $h = 0
    $sat = 0
    if ($max -ne $min) {
        $delta = $max - $min
        if ($l -gt 0.5) { $sat = $delta / (2 - $max - $min) } else { $sat = $delta / ($max + $min) }
        if ($max -eq $r) { $h = 60 * ((($g - $b) / $delta) % 6) }
        elseif ($max -eq $g) { $h = 60 * ((($b - $r) / $delta) + 2) }
        else { $h = 60 * ((($r - $g) / $delta) + 4) }
        if ($h -lt 0) { $h = $h + 360 }
    }
    return @{
        H = [int]($h + 0.5)
        S = [int]($sat * 100 + 0.5)
        L = [int]($l * 100 + 0.5)
    }
}

function Get-Verdict($hsl) {
    $h = $hsl.H; $s = $hsl.S; $l = $hsl.L
    if ($s -lt 10 -and $l -le 12) { return 'BAN-NEUTRAL near-black used as main color' }
    if ($h -ge 236 -and $h -le 305 -and $s -ge 30) { return 'BAN-PURPLE purple or indigo family' }
    if ($h -ge 205 -and $h -le 250 -and $l -lt 45 -and $s -ge 30) { return 'BAN-DEEPBLUE deep blue family' }
    if ($h -ge 205 -and $h -le 250 -and $l -lt 62 -and $s -ge 30) { return 'BAN-ROYALBLUE royal blue family' }
    return ''
}

$files = Get-ChildItem -LiteralPath $Path -Recurse -File -ErrorAction SilentlyContinue |
    Where-Object { $Extensions -contains $_.Extension.ToLower() }

$hits = 0
foreach ($file in $files) {
    $found = Select-String -LiteralPath $file.FullName -Pattern $hexPattern -AllMatches -Encoding utf8
    foreach ($row in $found) {
        foreach ($m in $row.Matches) {
            $hsl = ConvertTo-Hsl $m.Value
            $verdict = Get-Verdict $hsl
            if ($verdict -ne '') {
                $hits++
                '{0}:{1}  {2}  H{3} S{4} L{5}  {6}' -f $file.FullName, $row.LineNumber, $m.Value, $hsl.H, $hsl.S, $hsl.L, $verdict
            }
        }
    }
}

if ($hits -eq 0) {
    'PASS: 0 suspicious hex in {0} file(s)' -f $files.Count
    exit 0
} else {
    'FAIL: {0} suspicious hex found' -f $hits
    exit 1
}
```

运行方式：

```powershell
Set-ExecutionPolicy -Scope Process Bypass -Force
pwsh -File .\check-main-color.ps1 -Path .\src
```

不需要建脚本时，用一行快速初筛，只查已知的违规色值：

```powershell
Get-ChildItem .\src -Recurse -File |

  Select-String -Pattern '#(000000|111111|1A1A1A|1F1F1F|7C3AED|8B5CF6|A855F7|6366F1|9333EA|C084FC|1E3A8A|1E40AF|1D4ED8|2563EB|0F2C5C|0F172A|172554|111827|1E293B)' -AllMatches
```

通过标准：

- 脚本输出 `PASS`，退出码 0；有命中就逐条改到 0。
- 产物里的 hex 一律写满 6 位，禁止 #fff 这类缩写，缩写会让脚本漏检，也让后续换色无法定位。
- 扫描范围只包括产物代码目录和设计 token 文件，不扫本文档；本文档里的违规 hex 是规则样本。
- 颜色只允许出现在三个位置：原始色板定义、语义 token、图表配置。业务样式里出现裸 hex，按未 token 化处理，先收进 token 再谈颜色对错。
- 命中但不确定用途的色值，人工确认它出现的位置：只用于正文、边框、次要文字且在 9 档中性色阶内，才算中性角色；出现在按钮、选中态、链接、图表第一序列、顶栏、Hero 就按违规改色。
